### AES-GCM Benchmark

The AES-GCM benchmark was revised so that nonce generation is excluded
from the AES-GCM encryption-latency measurement.

End-to-end throughput includes nonce generation and AES-GCM encryption.

#### Configuration

- Algorithm: AES-256-GCM
- Key size: 256 bits
- Plaintext size: 12 bytes
- Nonce size: 12 bytes
- Authentication tag size: 16 bytes
- Warm-up records: 1,000

- Benchmark runs: 5
